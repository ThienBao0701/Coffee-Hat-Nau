## Where to start

- **UI screen:** start at the relevant `src/main/java/cafe/view/...` panel, inspect its service calls and `UiTask` callbacks, then follow into the service.
- **Business rule:** find the service method listed above; check its permission, validation, `Database.tx` scope, and downstream DAO methods.
- **SQL query:** inspect the owning `src/main/java/cafe/dao/*Dao.java`; all DAO SQL should use `Jdbc`/prepared statements.
- **Schema relationship:** read `src/main/resources/db/schema.sql` and cross-check DAO joins/foreign keys. Seed changes belong in `seed-demo.sql` only when they support deterministic demo/tests.
- **Permission:** inspect `util/Permission.java`, `util/Session.java`, the service method's `Session.require`, and `view/MainFrame.java` navigation filter.
- **Payment calculation:** `service/PriceCalculator.java` + `util/Money.java`, then `OrderService.preview/pay`, `InvoiceDao.markPaid`, `ReceiptFormatter`.
- **Inventory operation:** `InventoryService` first. Keep balance writes within `applyMovement`, inspect transaction and `InventoryDao` locks, then update `ServiceIntegrationTest` expectations.
- **Report:** `ReportService` for date semantics/aggregation, `ReportDao` for source rows, then `Reports` and `ReportPanel`.
- **Cash drawer:** `CashShiftService` for ownership, locking and reconciliation; `CashShiftDao` for shift/movement persistence; payment/refund linkage is in `OrderService` and `InvoiceDao`.
- **Integration/regression test:** use `TestSupport.newServices()` and `ServiceIntegrationTest`; calculator/receipt/persistence/UI construction each have focused test classes. Tests use H2 in MySQL mode, not a real MySQL server.
